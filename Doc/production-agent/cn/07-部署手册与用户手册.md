# 第一部分：部署手册

## 一、环境要求

### 1.1 运行环境
| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10+ / Linux（Docker） |
| Node.js | 22+ |
| 包管理 | npm（Monorepo workspace） |

### 1.2 依赖组件
| 组件 | 版本 | 用途 |
|------|------|------|
| SQL Server | 内网 ERP | 源生产数据（只读账号） |
| PostgreSQL | 15+ | 看板本地库（`web/prisma`） |
| LLM API | 百炼/DeepSeek | 模型推理（`AI_API_KEY`） |
| Docker | 20+ | 容器化部署 |

## 二、配置项说明

主配置 `pi_agent/.env`（不入库、不入镜像）：

| 变量 | 说明 |
|------|------|
| `AI_PROVIDER` | 模型供应商，默认 `bailian` |
| `AI_API_KEY` | 模型 API Key（必填） |
| `AI_MODEL` | 主模型，默认 `qwen3.8-max` |
| `AI_MODEL_FALLBACKS` | 降级模型链，默认 `glm-5.2,qwen3.7-max` |
| `SQL_HOST` / `SQL_PORT` / `SQL_DB` / `SQL_USER` / `SQL_PASSWORD` | SQL Server 连接 |
| `PORT` | 服务端口，默认 8001 |
| `SYNC_API_KEY` | MaxKB（/v1）鉴权 Key |
| `OPEN_API_KEY` | 开放接口（/open）鉴权 Key |

Web 侧：`AI_API_URL`（默认 `http://127.0.0.1:8001`）、PostgreSQL DATABASE_URL。模型定义 `deploy/models.json`（bailian provider）。

## 三、部署步骤

### 3.1 本地开发
```bash
npm install
npm run dev --workspace=server   # 后端 :8001（自动加载 pi_agent/.env）
npm run dev --workspace=web      # 前端 :3001
```

### 3.2 Docker（生产）
```bash
cp deploy/.env.production deploy/.env    # 填入真实密钥
docker compose -f docker-compose.simple.yml up -d --build   # 内网推荐（无 nginx）
# 或带 nginx：
docker compose up -d --build
# 首次/模型变更后：
docker cp deploy/models.json <agent容器>:/root/.pi/agent/models.json
```

### 3.3 数据库
- 看板库：`cd web && npx prisma migrate deploy && npm run seed`（或 `web/scripts/seed-orders.ts`）

## 四、运维监控

| 指标/日志 | 位置 | 说明 |
|------|------|------|
| 健康检查 | `GET /health` | 返回 `{status:"ok"}` |
| 会话 trace | `data/logs/traces/{日期}.jsonl` | 每请求工具+耗时+错误 |
| 开放接口审计 | `data/logs/open-api-requests.jsonl` | 谁何时查了哪个订单 |
| MaxKB 请求日志 | `data/logs/maxkb-requests.jsonl` | 模型名路由排查 |
| 控制台日志 | 标准输出 | 带 `[scope]` 标签 |

会话 30 分钟无活动自动清理；tracer/审计日志建议定期清理。

# 第二部分：用户手册

## 一、功能操作指南

### 1.1 聊天查单（/chat）
- 输入订单号：`查 EX20260804-1042 进度`
- 按技术员：`张三目前的订单情况`
- 按维度：`广州小试这一个月的订单`
- 产能：`哪个基地负荷低` / `推荐下单基地` / `在 XX 基地下单要多久`
- 回复末尾附反馈表链接；可折叠查看模型思考链与工具调用卡片

### 1.2 生产看板（/dashboard）
- 查看各业务类型分组 KPI（生产中/已完成/逾期/预警/异常）
- 工序分布、Top5 活跃订单、逾期/临近交期预警列表

### 1.3 基地管理（/bases）
- 查看基地列表、新增基地（名称/位置/设备台数/单台日产量）

### 1.4 产能（/capacity）
- 查看各基地负荷率、日产能、待处理、完工天数图表

## 二、配置说明

- 用户无配置项；管理员通过 `.env` 调整模型、SQL 连接、鉴权 Key
- 会话置顶/重命名/删除在侧边栏会话列表操作

## 三、常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 查不到订单 | 单号有误 / 审批未走完 / 超 3 个月窗口 | 核对单号、确认 PLM/OA 审批、说明窗口限制 |
| 返回「待排产」 | 订单已登记未排产 | 告知用户订单已登记、尚未排产 |
| 回复 `[error] ...` | 模型额度用尽 / Key 失效 | 检查 AI_API_KEY、续费或更换模型 |
| /v1 401 | SYNC_API_KEY 不匹配 | 核对 MaxKB 与 server 两侧 Key |
| /open 503 | OPEN_API_KEY 未配置 | 在 `.env` 配置 OPEN_API_KEY |
| 会话历史为空 | JSONL 目录变更/未持久化 | 确认 `PI_CODING_AGENT_DIR`、会话文件路径 |
| 看板无数据 | SQL 不通且无 seed | 检查 SQL 连接、执行 seed |
| 端口冲突 | Docker 占用 8000/80 | dev 用 8001/3001，避开 Docker |
