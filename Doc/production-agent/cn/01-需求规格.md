## 一、功能概述

中试生产管理 AI 聊天平台。基于 `pi-coding-agent` 框架，TypeScript Monorepo（`pi_agent` + Hono server + Next.js web）。

核心目标：**让业务员输入订单号（或技术员/牌号/产品线等维度）就能自助查询生产进度、产能负荷、下单推荐与交期，无需人工咨询计划岗。**

一句话链路：业务员输入订单号 → LLM 调度领域工具查询 SQL Server → SSE 流式返回格式化结果。

服务三大人群：

| 用户 | 典型需求 |
|------|----------|
| 计划岗 / 中试主管 | 掌握全局生产状态，快速查单 |
| 营销中心业务员 | 查询自己订单的进度 |
| 技术中心工程师 | 了解生产进度与产能情况 |

## 二、功能需求清单

### 2.1 订单进度查询（核心功能）
- 按订单号点查：返回各工序负责人、完成时间、异常信息
- 支持 5 个业务范围：广州工艺实验 / 广州送样&小订单 / 小试（全集团）/ 上海工艺实验 / OA辅助单（全集团）
- 未指定业务范围时并行查全部 5 类取命中
- 未排产订单兜底（登记表）查询
- 多料次订单（上海工艺实验）逐料次呈现

### 2.2 订单列表查询（多维）
- 按技术员 / 牌号 / 产品线 / 业务类型 / 基地 / 排产时间范围批量查单
- 业务类型支持别名（研发实验=小试、工艺实验=广州+上海等）
- 返回总数、已完成数、按产品线统计

### 2.3 产能负荷分析
- 查询单基地或全基地负荷率、超负荷倍数、完工天数

### 2.4 下单基地推荐
- 基于负荷率最低原则推荐最优下单基地并说明理由

### 2.5 交期估算
- 估算指定基地下新订单的交期天数

### 2.6 会话管理
- 对话历史列表、详情、重命名、删除、置顶
- 会话 JSONL 持久化 + 上下文自动压缩

### 2.7 多智能体分流
- 按模型名（`production-agent-gz` / `production-agent-main`）钳制业务范围

### 2.8 开放接口
- `/open/orders/progress`、`/open/orders/list` 供外部系统程序化查询

### 2.9 生产看板（Web）
- Dashboard 看板（KPI、工序分布、逾期/预警、Top5）
- 基地管理、产能展示页面

## 三、业务规则需求

### 3.1 只读系统
生产数据只读，任何情况下不可修改。`permissionGuard` 硬编码禁止 `write/delete/update` 前缀工具。

### 3.2 数据窗口（3 个月硬限制）
所有查询只查最近 3 个月内有工序活动的订单；查不到时如实告知窗口限制，不得断定订单不存在。

### 3.3 未排产订单
订单需通过 PLM 和 OA 审批后才流转进 MYEXCEL 排产；排产前只登记在登记表，主表查不到，需降级查登记表并如实告知「已登记、尚未排产」。

### 3.4 完成判定
- 小试：完成信号 = 注塑完成时间
- OA辅助单：完成信号 = 注塑样条时间
- 上海工艺实验：整单完成以「最后料次」为准

### 3.5 业务类型别名
研发实验=小试；工艺实验=广州工艺实验+上海工艺实验；注塑单/研发辅助单=OA辅助单；送样/小订单=广州送样&小订单；实验单含 OA辅助单。

### 3.6 权限矩阵
`sales`/`engineer`/`planner`/`supervisor` 四角色可读；计划岗（planner）只能查本基地数据。

### 3.7 时间语义
工具返回时间已是北京时间墙钟；「未设置」时间（`1900/1899` 哨兵、空串）一律归一为 `null`，不得当作真实完成时间。

## 四、非功能需求

### 4.1 性能要求
- SSE 流式响应，首 token 快速可见
- SQL Server 连接池复用（agent 池 max=10，web 池 max=5），请求超时 30s
- 多业务类型并行查询（`Promise.all`）
- 列表明细 `TOP` 截断（默认 200 条），统计单独不截断

### 4.2 安全要求
- 所有 SQL 参数化（`@param` 绑定），禁止字符串拼接
- 开放接口 fail-closed：未配置 `OPEN_API_KEY` 一律 503
- 开放接口独立 Key（`OPEN_API_KEY`）与 MaxKB 的 `SYNC_API_KEY` 隔离不同信任域
- 工具白名单：LLM 仅可调用 7 个领域工具，无 filesystem/shell/network

### 4.3 可用性要求
- 模型额度用尽自动降级到下一模型（降级链）
- SQL 失败时工具层降级 mock（仅对话场景，开放接口不降级）
- 会话 30 分钟无活动自动清理
