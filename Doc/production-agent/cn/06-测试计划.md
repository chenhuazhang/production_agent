## 四、边界条件测试

- 日期边界：`since`=`until`=当天；`since>until`（应拒绝）；日期非 `YYYY-MM-DD`（应拒绝）
- 数据窗口边界：查询第 3 个月 ± 1 天的订单（窗口硬限制）
- 订单号边界：空、超 64 字符、大小写、含/不含 EX
- 料次边界：料次号不连续（1,2,7,9）、单料次、多料次全完成
- limit 边界：`limit=0`（应拒）、`limit>1000`（截到 1000）、负数
- 空结果：`total=0`、明细空但统计有值（截断场景）

## 五、测试数据准备

- **SQL Server 源数据**：因只读，依赖真实 ERP 数据；测试用已知真实订单号（含 EX / 非 EX / 上海多料次 / OA）
