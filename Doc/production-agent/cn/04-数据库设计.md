### 1.2 看板本地库（PostgreSQL，`web/prisma`）

#### bases
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(cuid) | 主键 |
| name | String | 基地名 |
| location | String | 位置 |
| dataSource | String | 业务类型（广州工艺实验/广州送样&小订单/上海工艺实验/小试/OA辅助单） |
| machineCount | Int | 设备台数 |
| perMachineDailyOutput | Int | 单台日产量 |
| active | Boolean | 是否启用 |

#### capacity_snapshots
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(cuid) | 主键 |
| baseId | String | 外键→bases |
| pendingOrders | Int | 待处理订单数 |
| dailyCapacity | Int | 日产能 |
| loadRate | Float | 负荷率 |
| overloadMultiplier | Float | 超负荷倍数 |
| daysToComplete | Float | 完工天数 |
| snapshotDate | DateTime | 快照日期 |

#### orders
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(cuid) | 主键 |
| baseId | String | 外键→bases |
| orderNumber | String(unique) | 订单号 |
| productName | String | 产品名 |
| customerName | String | 客户名 |
| machine | String? | 机台 |
| orderCount | Float | 批次数量 |
| status | String | not_started/in_progress/completed |
| priority | String | normal/urgent |
| deliveryDate | DateTime | 交期 |
| currentStage | String? | 当前工序 |
| extrusionException / injectionStripException / injectionColorPlateException | Boolean | 三种异常 |

#### process_stages
| 字段 | 类型 | 说明 |
|------|------|------|
| id | String(cuid) | 主键 |
| orderId | String | 外键→orders（级联删除） |
| name | String | 工序名 |
| status | String | pending/in_progress/completed |
| person | String? | 负责人 |
| completedAt | DateTime? | 完成时间 |
| sortOrder | Int | 排序 |

#### conversations / messages
| 字段 | 类型 | 说明 |
|------|------|------|
| conversations.id / baseId / userId / title | - | 预留会话表 |
| messages.id / conversationId / role / content / toolCalls / toolResults | - | 预留消息表（实际会话走 JSONL，未用此表） |

## 三、索引建议

| 表 | 索引字段 | 类型 | 说明 |
|------|----------|------|------|
| orders | orderNumber | 唯一索引 | 订单号精确查询 |
| orders | baseId | 普通索引 | 按基地过滤 |
| process_stages | orderId, sortOrder | 复合索引 | 按工序排序读取 |
| capacity_snapshots | baseId, snapshotDate | 复合索引 | 最新快照查询 |
| SQL Server `tabdiytable3393` | f52977 | 建议（源系统） | 订单号点查主键语义 |
| SQL Server 各表时间列 | f52994/f140799 等 | 建议 | 3 个月数据窗口过滤 |
